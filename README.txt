# NFL Scoreboard

## Built With
* **Vibe Coded** via [GPT-6, Gemini 3.5]
* **Python 3.x** - Core application logic
* **Tkinter** - Desktop Graphical User Interface (GUI)


**Developed by Joseph Statkevicus**

A real-time, desktop NFL Scorecard application built with Python and Tkinter. Personalize your scoreboard with your favorite team's official color schemes, view live score updates from ESPN, and hear an automated touchdown audio alert whenever your team scores!

---

##  Features

-  **Dynamic Team Themes**: Select any of the 32 NFL teams to immediately apply their primary, accent, and foreground color schemes.
-  **Clean Team Badges**: Displays 2–3 letter team abbreviations.
-  **Live ESPN Updates**: Fetches real-time scores, opponent data, and game status indicators via ESPN's public scoreboard API every 15 seconds.
-  **Touchdown Audio Alert**: Plays a custom audio track whenever your selected team scores a touchdown (including extra points and 2-point conversions).
-  **Persistent Settings**: Saves your favorite team selection locally so it automatically loads whenever you open the app.
-  **Full-Screen Display**: Designed to run cleanly in full-screen mode.

---

##  Downloading & Installing (Windows)

To run the application on Windows:

1. Download **`NFLScoreSetup.exe`** from the latest release.
2. Double-click **`NFLScoreSetup.exe`** and follow the installer instructions.
3. Launch **NFLScore** straight from your Desktop or Start Menu!

> **Note on Windows SmartScreen**: Because this app is an independent executable, Windows Defender SmartScreen may display a warning on first launch. Click **"More info"** and then **"Run anyway"** to open the installer.
